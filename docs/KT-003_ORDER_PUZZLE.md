# KT-003 — УСТАРЕЛО: отменённая механика коридоров

Этот документ сохранён для истории разработки. Его правила больше не действуют.

Отменены: поиск пути от входа, коридоры, каменные препятствия, отдельные партии добычи, лимит ошибок и поражение за неправильный выбор цвета.

Актуальные правила находятся в [GAMEPLAY_SPEC.md](GAMEPLAY_SPEC.md): пиксельный рисунок, доступность по четырём сторонам, контейнеры с ограниченным числом муравьёв и пять пусковых ячеек.
