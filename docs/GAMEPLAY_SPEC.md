# «Муравьишки: Пиксельная охота» — игровая спецификация

## Основная механика

Самостоятельная цветная пиксельная головоломка на Godot 4. Это отдельный проект, не связанный с Game-ANTS. Ориентир — общий игровой принцип Food Hunt: Pixel Puzzle, без копирования чужих уровней, графики, интерфейса, текстов или звуков.

### Поле и доступность
- Поле представляет собой цельный рисунок из разноцветных пиксельных блоков.
- Пиксель доступен, если хотя бы одна из его четырёх ортогональных сторон открыта: за этой стороной находится пустая клетка или край поля.
- Пиксель, окружённый с четырёх сторон другими пикселями, недоступен.
- Когда муравьи уносят пиксель, соседние пиксели могут стать доступными. Доступность пересчитывается после каждого удаления.

### Контейнеры и пусковые ячейки
- На экране ровно пять пусковых ячеек.
- Контейнеры выдаются игроку строго по одному, последовательно.
- Игрок выбирает свободную пусковую ячейку, в которую помещает следующий контейнер.
- Контейнер запускается автоматически сразу после помещения; отдельной кнопки запуска нет.
- Контейнеры автоматически обрабатываются по приоритету слева направо. Поэтому выбранная ячейка задаёт позицию контейнера в порядке обработки относительно уже ожидающих контейнеров.
- В каждом контейнере свой цвет муравьёв и ограниченное количество муравьёв. Количество может различаться от контейнера к контейнеру.
- Один муравей уносит один пиксель только своего цвета.
- Контейнер забирает все доступные пиксели своего цвета, пока хватает муравьёв. После каждого удаления проверяется, не открылся ли новый пиксель того же цвета.
- Если подходящего доступного пикселя нет или муравьёв в контейнере пока недостаточно, контейнер остаётся в своей пусковой ячейке и ждёт, пока другие действия откроют ему добычу. Израсходованный контейнер освобождает ячейку.

### Победа и поражение
- Победа: на поле не осталось пикселей.
- Поражение наступает только при одновременном выполнении условий:
  1. все пять пусковых ячеек заняты;
  2. ни один размещённый контейнер не может унести доступный пиксель своего цвета;
  3. на поле ещё остались пиксели.
- Неподходящий цвет или временное отсутствие доступной добычи сами по себе не являются ошибкой и не завершают уровень.
- Если есть хотя бы одна свободная пусковая ячейка, игрок может продолжать получать и размещать контейнеры.

## Текущий технический прототип

KT-005 заменяет ошибочную механику коридоров и поиска пути. Тестовая сцена содержит:
- авторский цветной рисунок 7×7;
- проверку доступности по четырём сторонам;
- пять пусковых ячеек;
- последовательную очередь контейнеров с разным количеством муравьёв;
- автоматический запуск при помещении и обработку пусковых ячеек слева направо;
- автоматическое поедание всех доступных пикселей соответствующего цвета в пределах числа муравьёв;
- ожидание контейнеров, которым пока не открыта добыча;
- тестовую слоистую раскладку: внешнее кольцо, внутреннее цветовое кольцо и закрытая центральная область;
- очередь из 12 контейнеров, суммарное число муравьёв в которой совпадает с количеством пикселей каждого цвета на поле;
- проверку победы и строгую проверку поражения по трём условиям выше.

Это механический прототип, не финальный баланс и не финальная графика. Проверка импорта и запуска в Godot 4, а также мобильные тесты ещё обязательны.
