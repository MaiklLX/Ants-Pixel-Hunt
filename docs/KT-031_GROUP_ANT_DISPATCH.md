# KT-031 — групповой выход муравьёв

## Поведение
При появлении подходящего бокса планировщик сразу считает все доступные блоки его цвета. На каждый такой блок назначается отдельный муравей, но не больше оставшегося количества муравьёв в боксе. Поэтому из одного отсека может выбежать целая группа, а не один работник за раз.

## Безопасность параллельной работы
- Целевые клетки резервируются перед запуском анимаций.
- Планировщик учитывает уже летящих к цели муравьёв, чтобы не выдать лишние задания сверх остатка бокса.
- После фактического захвата резерв освобождается; открывшиеся блоки сразу попадают в следующую волну.
- Бокс уезжает по конвейеру только после возврата последнего муравья из его группы.
