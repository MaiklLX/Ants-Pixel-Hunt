## Реализовано
- Web/PWA на HTML5, CSS, JavaScript и Vite.
- Поле 35×35 крупных цветных блоков, последовательная очередь боксов 3×3 и пять стартовых слотов.
- Боксы запускают муравьёв своего цвета; один муравей переносит один блок.
- Правило доступности блока: только наружный слой, связанный с внешним пространством; закрытые внутренние полости не открывают блоки.
- Независимые волны, резервирование целей, прогресс уровня, победа/поражение.
- Индивидуальные плавные извилистые маршруты и визуальная переноска кубика.
- Прогресс кампании (список открытых полянок) хранится в localStorage; состояние незавершённой партии намеренно не сохраняется. PWA shell cache.
- Отдельный Godot-прототип хранится в репозитории; публичная браузерная игра — Web/PWA.

## KT-037 — ранняя диспетчеризация и безопасное закрытие бокса
- Муравей переводится из фазы outbound в returning в момент подбора блока.
- Диспетчер считает ожидающими только outbound-муравьёв; возвращающиеся больше не блокируют следующую волну.
- Бокс разрешено отправить на конвейер только когда в worker registry больше нет ни одного муравья его отсека.
- Визуальный счётчик показывает число муравьёв, которые ещё в пути, пока бокс ожидает возврата.
- Задержка между стартами сокращена до короткой волны; анимация загрузки бокса ускорена без изменения маршрутов муравьёв.


## KT-038 — синхронное обновление Web/PWA и Android
- Фактический production worker расположен в public/service-worker.js; корневой service-worker.js не копируется Vite в dist.
- Новый worker использует cache v8, устанавливает свежий HTML и извлекает реальные production JS/CSS bundles.
- Навигация network-first с offline fallback; PWA при старте проверяет обновление worker без HTTP-кэша и перезагружает страницу после controllerchange.
- Android debug APK workflow запускается также на push в main.
- iPhone/iPad используют тот же web/PWA build через Safari; подписанный App Store IPA требует Apple signing и macOS build.

## KT-042 — наружный слой и мультяшный визуал
- Доступность блоков пересчитана через flood fill пустых клеток от внешней границы. Внутренняя замкнутая пустота больше не даёт доступ к блоку; игрок снимает рисунок снаружи внутрь.
- Поиск волн использует один список наружных блоков, чтобы не выполнять отдельный обход поля для каждого муравья.
- Исправлено пополнение очереди: используется фактическая длина колоды выбранного уровня. Это устраняет раннее завершение подачи боксов на уровнях, чья колода длиннее базовой.
- Canvas блоков перерисован как мультяшные объёмные плитки: мягкие тени, градиентные грани, верхние блики и контур доступного слоя.
- CSS получил более яркую, игрушечную стилистику поверхностей, отсеков, боксов и конвейера.
- Добавлены регрессионные тесты на закрытые внутренние полости, открытие через внешний коридор и refill выбранного уровня.
- PWA cache v12; app-version KT-042.
