## Что сейчас реализовано
- Браузерная игра HTML5 / CSS / JavaScript на Vite.
- Игровое поле 35×35 крупных цветных блоков.
- Пять стартовых слотов; последовательная очередь боксов 3×3.
- Бокс автоматически запускает муравьёв своего цвета; лимит муравьёв соответствует количеству блоков в боксе.
- Доступность блока определяется свободной ортогональной стороной или краем поля.
- Муравьи работают независимыми волнами, цели резервируются, блок удаляется при захвате.
- Индивидуальные плавные извилистые маршруты; визуально муравей несёт блок.
- Прогресс уровня и экраны победы/поражения.
- Локальное сохранение: IndexedDB с резервом в localStorage.
- PWA Service Worker для оболочки и статических ресурсов.
- Отдельный Godot-прототип хранится в репозитории; он не является текущей публичной браузерной реализацией.
