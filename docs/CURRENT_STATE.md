## Реализовано
- Web/PWA на HTML5, CSS, JavaScript и Vite.
- Поле 35×35 крупных цветных блоков, последовательная очередь боксов 3×3 и пять стартовых слотов.
- Боксы запускают муравьёв своего цвета; один муравей переносит один блок.
- Правило доступности блока: только наружный слой, связанный с внешним пространством; закрытые внутренние полости не открывают блоки.
- Независимые волны, резервирование целей, прогресс уровня, победа/поражение.
- Индивидуальные плавные извилистые маршруты и визуальная переноска кубика.
- Размеры боксов различаются, общий лимит каждого цвета равен числу блоков этого цвета; неверная очередность может занять все пять отсеков.
- Одновременно анимируется не более 36 муравьёв; общий canvas обновляется с ограничением около 30 FPS и пониженными затратами на DPR.
- После подбора обновляются только удалённая клетка и вновь открытые блоки, без полной перерисовки поля и пересоздания карточек очереди.
- Прогресс кампании (список открытых полянок) хранится в localStorage; состояние незавершённой партии намеренно не сохраняется. PWA shell cache.
- Отдельный Godot-прототип хранится в репозитории; публичная браузерная игра — Web/PWA.

## KT-037 — ранняя диспетчеризация и безопасное закрытие бокса
- Муравей переводится из фазы outbound в returning в момент подбора блока.
- Диспетчер считает ожидающими только outbound-муравьёв; возвращающиеся больше не блокируют следующую волну.
- Бокс разрешено отправить на конвейер только когда в worker registry больше нет ни одного муравья его отсека.
- Визуальный счётчик показывает число муравьёв, которые ещё в пути, пока бокс ожидает возврата.
- Задержка между стартами сокращена до короткой волны; анимация загрузки бокса ускорена без изменения маршрутов муравьёв.
