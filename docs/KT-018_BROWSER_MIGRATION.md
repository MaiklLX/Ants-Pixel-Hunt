# KT-018 — переход на HTML5 / PWA / Capacitor

Дата: 10.11.2026

## Решение
По прямому подтверждению пользователя проект переводится с Godot на браузерную архитектуру. Исходная реализация Godot KT-017 сохранена без изменений в ветке `legacy/godot-kt017-2026-11-10`. Разработка браузерной версии ведётся отдельно в `migration/browser-html5-2026-11-10`. Браузерная версия KT-018 объединена с публичной веткой `main` через PR #1 (squash commit `c895fb9a3d7bdf159f9a8fa1ed5baf530f583ce1`). Исходники Godot KT-017 сохранены в legacy-ветке.

## Целевая архитектура
- HTML/CSS/JavaScript — единая игровая реализация.
- Vite — сборка статического web-клиента.
- PWA manifest + service worker — установка на iOS через Safari и автономный запуск.
- IndexedDB с fallback на localStorage — локальный прогресс без сервера.
- Capacitor Android — оболочка для последующей сборки APK.
- Node.js test runner — регрессионные проверки правил.

## Сохранённые правила
- Авторское поле 7×7 и исходная очередь из 17 контейнеров перенесены из Godot-прототипа.
- Пять пусковых ячеек.
- Доступность определяется четырьмя ортогональными соседями и краем поля.
- Один муравей переносит один пиксель своего цвета.
- Автоматический запуск и обработка строго слева направо.
- Новые пиксели того же цвета могут открываться в том же цикле сбора.
- Поражение только при занятых пяти ячейках, отсутствии доступного хода у всех контейнеров и оставшихся пикселях.
- Победа при полном очищении поля.

## Состав первого браузерного среза
- Адаптивный интерфейс под портретные телефоны.
- CSS-анимация авторского муравья и переноса пикселя.
- Локальные сохранения и восстановление.
- PWA-кеширование оболочки приложения.
- Capacitor config и Android-зависимости.
- Первичные Node-тесты.

## Что ещё не подтверждено
- npm install / npm test / production build ещё не запускались в CI.
- Реальная установка PWA на iPhone не проверена.
- Android APK ещё не собран и не проверен на устройстве.
- Финальная графическая полировка, звук, баланс и дополнительные уровни остаются следующими этапами.

## Контроль безопасности
Не удалять Godot-файлы и не переносить браузерную версию в `main` без отдельной проверки и решения о публикации.
