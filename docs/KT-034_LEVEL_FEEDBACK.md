# KT-034 — прогресс уровня и экран результата

## Задача
Сделать игровой цикл понятнее и эмоционально завершённее, не меняя правила сбора и доступности пикселей.

## Реализовано
- Добавлена полоса прогресса, показывающая процент собранного портрета.
- Счётчик поля формулируется как количество оставшихся кубиков.
- Победа и поражение показываются в отдельном модальном экране с разными заголовками и пояснениями.
- Из экрана результата можно повторить уровень или вернуться в главное меню.
- Состояние результата корректно отображается после восстановления сохранённой партии.
- Обновлён PWA cache key до v12.
- README и игровая спецификация приведены к текущей браузерной реализации.

## Не менялось
- Размер поля 35×35 и авторский рисунок.
- Правила доступности блоков, пять пусковых отсеков и конвейер.
- Автоматическая работа независимых муравьиных групп.
- Локальный формат сохранения.

## Проверка
- Автоматические тесты игровой логики и production build запускаются GitHub Actions на push.
- Требуется визуальная проверка результата на мобильном устройстве и в браузере после публикации.
