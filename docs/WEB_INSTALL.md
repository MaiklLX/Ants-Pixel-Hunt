# Установка браузерной версии

Адрес игры после публикации: https://maikllx.github.io/Ants-Pixel-Hunt/

Если адрес не открывается, откройте Settings → Pages в репозитории и установите Source: GitHub Actions. После этого в Actions запустите workflow «Publish browser game to GitHub Pages».

## iPhone / iPad
1. Откройте опубликованную HTTPS-страницу игры в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Запустите игру с нового значка. После первой загрузки приложение сможет открываться офлайн при наличии сохранённого кеша.

## Android
Браузерную версию можно установить как PWA из поддерживаемого браузера. Отдельный APK будет собираться через Capacitor после генерации Android-проекта и проверки сборки.

## Сохранения
Прогресс хранится локально в IndexedDB; при недоступности IndexedDB используется localStorage. Сервер для игрового сохранения не требуется.
