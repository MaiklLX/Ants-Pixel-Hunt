# KT-098 — согласование внешнего слоя светлячка и восстановление CI

**Дата:** 15 ноября 2026.  
**Статус:** кодовый checkpoint подтверждён тестами, production build и Pages deployment. Godot и Android workflow для code SHA были запущены; итог на момент документирования ещё ожидался.

## Что обнаружено

Фактический HEAD main перед работой: `c242476f074967397350aa911cce4b31a703e4e6`.

GitHub Actions для KT-097 не были зелёными, хотя предыдущий отчёт ошибочно описывал независимую модельную проверку как достаточное подтверждение. Pages run [#43579512314](https://github.com/MaiklLX/Ants-Pixel-Hunt/actions/runs/43579512314) и Android run [#43579512210](https://github.com/MaiklLX/Ants-Pixel-Hunt/actions/runs/43579512210) завершились failure: 85 из 87 тестов прошли.

Обнаружены две реальные проблемы:

1. Старый тест уникальности кампании требовал ровно шесть уровней (`LEVELS.length === 6`), поэтому добавление седьмой полянки закономерно сломало тест.
2. Цветовые слои светлячка строились по расстоянию от внешнего пустого воздуха, но игровой `getExposedPixels` дополнительно считает занятые клетки на границе поля открытыми. Клетка `(17,34)` была доступна сразу, но имела голубой цвет. Это нарушало контракт «весь начальный открытый слой зелёный».

## Исправление

- В `createFireflyBoard` все занятые клетки, касающиеся границы поля, добавляются в BFS как виртуальные источники внешнего слоя с глубиной 1.
- Тесты кампании больше не зашивают число уровней в проверки уникальности и описаниях. Число уникальных рисунков сравнивается с `LEVELS.length`.
- Специальный тест KT-097 по-прежнему явно требует семь уровней, проверяет только зелёный начальный слой, точные бюджеты и полное прохождение.
- Правила головоломки, очередь, пять стартовых слотов, лимиты боксов, движение муравьёв и сохранения не менялись.
