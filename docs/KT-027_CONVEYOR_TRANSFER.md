# KT-027 — естественная подача боксов через конвейер

## Цель
Сделать перемещение выбранного бокса из резервной сетки 3×3 в первый свободный стартовый отсек понятным и визуально приятным. Бокс не должен просто исчезать из резерва и мгновенно появляться в отсеке.

## Реализация
- При выборе верхнего бокса резервная колонка начинает сдвигаться вверх по прежнему правилу.
- Сам бокс визуально поднимается с карточки, попадает на сортировочную ленту и едет по ней.
- На ленте виден отдельный небольшой объёмный картонный контейнер: крышка, сгибы, цветное содержимое и наклейка.
- После движения по ленте контейнер плавно уходит в первый свободный стартовый отсек.
- Пока идёт доставка, целевой отсек показывает состояние «ПРИЁМ», а повторный выбор блокируется, чтобы не смешивать анимации и порядок заполнения.
- Только после прибытия начинается работа муравьёв.
- Обратная отгрузка опустевшего бокса использует тот же визуальный образ коробки.
- При reduced-motion убирается бесконечное движение ленты и мигающая анимация приёма.

## Инварианты
- Игровые правила, порядок слотов и количество муравьёв не меняются.
- Выбранный бокс занимает первый свободный слот.
- Сдвиг колонок 3×3 и детерминированная очередь сохраняются.
- Логика сохранения не зависит от временного визуального состояния доставки.
- На мобильном экране остаётся вся игра целиком, без прокрутки.

## Проверка
Запустить npm test и npm run build, затем визуально проверить короткий и высокий экран iPhone/Android: движение должно начинаться из выбранной карточки, идти по ленте и завершаться точно в активном отсеке.
