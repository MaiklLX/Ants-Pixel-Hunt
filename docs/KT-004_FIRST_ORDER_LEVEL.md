# KT-004 — первый уровень с зависимостью от порядка

## Реализовано в прототипе

В `scripts/main.gd` добавлен первый пространственный тест стратегической механики:

- поле 5×5;
- каменные клетки формируют узкий коридор;
- вход расположен снизу;
- четыре партии добычи образуют цепочку: красная → синяя → жёлтая → красная;
- на старте доступна только красная партия у входа;
- после её удаления открывается синяя, затем жёлтая и последняя красная;
- доступность рассчитывается поиском пути по пустым клеткам от входа (обход по соседним клеткам);
- отряды одного цвета представлены отдельными кнопками;
- выбор цвета, у которого сейчас нет доступной партии, расходует одну ошибку;
- три ошибки завершают уровень поражением;
- есть победа и перезапуск.

## Проверяемая последовательность

Успешный маршрут:
1. Красный отряд А.
2. Синий отряд.
3. Жёлтый отряд.
4. Красный отряд Б.

Ошибочный пример:
1. Синий отряд до открытия синей партии — ошибка №1.
2. Красный отряд А — открывает проход.
3. Жёлтый отряд до открытия жёлтой партии — ошибка №2.
4. Зелёные разведчики — ошибка №3, поражение.

Не считать KT-004 завершённой до этих проверок. Следующий шаг — открыть проект в Godot 4, исправить возможные ошибки парсинга, выполнить обе последовательности и проверить экран на узком мобильном разрешении.
