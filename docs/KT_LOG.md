# Журнал контрольных точек — «Муравьишки: Пиксельная охота»

Этот журнал — краткая хронология подтверждённых этапов. При расхождении с кодом, CI или GitHub история переписки не считается источником истины: сверяй фактический main, файлы и Actions.

## Как вести журнал
- Добавляй запись только после фактического изменения или завершённого аудита.
- Для каждого изменения указывай KT, дату, краткий результат, затронутые файлы, commit SHA и проверки.
- Не записывай предполагаемые результаты как выполненные.
- Если этап не завершён, явно помечай его как «в работе» или «заблокирован».
- Не переписывай старые записи задним числом; исправления оформляй отдельной заметкой.
- Полные детали этапа храни в отдельном docs/KT-XXX_*.md, а здесь оставляй индекс и итог.
