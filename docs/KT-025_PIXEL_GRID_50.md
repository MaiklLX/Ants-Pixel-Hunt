# KT-025 — Сетка 50×50 и более детальные рисунки

## Решение по разрешению

- Видимое поле сохраняет размер 250×250 квадратов.
- Каждый собираемый цветной блок занимает 5×5 видимых клеток.
- Логическая доска рисунка теперь 50×50 — до 2 500 цветных блоков.
- Один муравей переносит один цельный блок 5×5; сбор не возвращается к одиночным точкам.
- Canvas остаётся растром 250×250, а игровые правила работают с компактной матрицей 50×50.
- Тонкие пустые швы между блоками подчёркивают пиксельную мозаику.

## Баланс

- Авторский портрет генерируется на сетке 50×50 по прежним формам и координатам, поэтому контуры и мелкие черты получают больше детализации.
- Максимум в боксе увеличен до 100 муравьёв/блоков, чтобы число выборов не росло пропорционально числу клеток.
- Колода детерминирована и содержит ровно столько муравьёв, сколько цветных блоков соответствующего цвета на рисунке.
- Счётчик показывает именно оставшиеся крупные блоки.
- Пять стартовых отсеков и резервная сетка 3×3 остаются без изменений.

## Сохранения

Сохранения с предыдущей логической сеткой 25×25 не совместимы с новым разрешением 50×50. При загрузке старого сохранения запускается свежий авторский уровень, чтобы не растягивать старые блоки и не искажать остатки ресурсов.

## Критерии приёмки

1. Видимое поле остаётся 250×250.
2. Логическая доска — 50×50.
3. Каждый собираемый блок занимает 5×5 клеток.
4. Один муравей переносит один блок целиком.
5. Колода покрывает все блоки каждого цвета без лишних муравьёв.
6. Сохраняются пять стартовых отсеков, 3×3 резерв и конвейер.
7. Тесты и production build проходят; публичная main не меняется без отдельного подтверждения.
