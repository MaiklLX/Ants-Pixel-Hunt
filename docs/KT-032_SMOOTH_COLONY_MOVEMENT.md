# KT-032 — плавное движение колонии

## Анимация
- Муравьи по-прежнему отправляются количеством, соответствующим числу доступных блоков их цвета.
- Внутри группы муравьи стартуют с небольшим разбросом по времени, сохраняя ощущение живой очереди.
- Каждый маршрут строится индивидуально: несколько мягких боковых отклонений объединены плавной Catmull–Rom кривой вместо прямой или одной дуги.
- Обратная дорога имеет похожий характер, но не повторяет путь пиксель в пиксель.
- Плавное ускорение/замедление делает старт и остановку менее механическими.
