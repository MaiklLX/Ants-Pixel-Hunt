# KT-293 — Реализация режима «Дзен»

## Игровой путь
1. Игрок открывает Дзен-мастерскую из главного меню.
2. Загружает PNG/WebP/JPG, настраивает 4–16 цветов и преобразует изображение в мозаику 35×35.
3. Кнопка «Играть в Дзен» сохраняет JSON рисунка в локальном хранилище этого браузера и открывает игру с параметром `?mode=zen`.
4. На главном экране доступна отдельная кнопка «Дзен-испытание», если на устройстве уже сохранён рисунок.
5. Для партии регистрируется отдельный временный уровень `zen-custom`; кампания и её карточки не меняются.

## Экономика попытки
- Каждый доставленный блок учитывается в счётчике попытки.
- За каждые 10 блоков отображается временный нектар: 1 🌼, с прибавкой от уровня Сада нектара.
- Временный запас не входит в постоянный баланс и не может быть потрачен на улучшения.
- При поражении временный запас обнуляется; исходный рисунок остаётся сохранённым. Кнопка повтора запускает тот же рисунок с нуля.
- Только после полной победы временный запас переводится в постоянный баланс; добавляется бонус завершения с учётом улучшений хранилища и питомника.
- Обычные кампанийные награды и отметки прохождения в Zen-партии не начисляются.
- Постоянный баланс, постройки и прогресс кампании не сбрасываются.

## Игровая логика
- Используется текущая тактическая механика: 5 стартовых отсеков, 3 линии коробок, последовательность очереди и автоматические муравьи.
- Очередь строится по фактическим цветам импортированного рисунка.
- Для пользовательского рисунка не создаются кампанийные препятствия; сложность определяется количеством блоков, цветами и последовательностью коробок.
- Очередь остаётся детерминированной и использует проверенный генератор кампании.
- Рисунок хранится локально в браузере; отдельный серверный профиль/синхронизация пока не реализованы.

## Проверки
- Добавлен тест регистрации пользовательского 35×35 рисунка и равенства количества блоков количеству муравьёв в очереди.
- Требуется подтвердить CI (Node tests, web build, Godot, Android) перед объявлением публикации.
