# KT-024 — Крупные пиксельные блоки

## Решение по размеру рисунка

- Видимая игровая доска остаётся квадратной сеткой 250×250.
- Для игрового расчёта соседние клетки объединены в блоки 10×10; логическая доска рисунка — 25×25 крупных блоков.
- Каждый крупный блок рисуется как отдельный цветной квадрат с тонким промежутком, чтобы пиксельная композиция читалась отчётливо.
- Один муравей забирает один крупный блок целиком. При возвращении в отсек исчезает весь квадрат 10×10, а не одна крошечная точка.
- Доступность, поиск соседей, распределение целей между слотами и условия победы/поражения работают на уровне крупных блоков.
- Canvas по-прежнему использует растр 250×250; DOM-элементы для клеток не создаются.

## Баланс текущего портрета

Текущая авторская картинка лягушонка содержит 325 собираемых блоков:

| Цвет | Блоков |
|---|---:|
| Зелёный | 165 |
| Сиреневый | 83 |
| Голубой | 31 |
| Жёлтый | 26 |
| Коралловый | 20 |
| **Всего** | **325** |

- Максимум в боксе — 20 муравьёв/блоков.
- Очередь содержит 19 боксов, в последнем боксе каждого цвета — только фактический остаток.
- Цвета в колоде перемежаются, чтобы сохранялся выбор порядка.
- Проверенная последовательность выбора колонок: 2, 0, 0, 2, 1, 0, 0, 0, 2, 0, 2, 2, 2, 0, 1, 0, 0, 1, 1.
- Регрессионный тест проигрывает полный уровень по реальным правилам доступности, волн муравьёв и освобождения отсеков.

## Сохранения и совместимость

Сохранение новой версии хранит логическую доску 25×25. Сохранения прежней версии с доской 250×250 намеренно не растягиваются и не интерпретируются как новая логическая сетка: при несовпадении размеров запускается свежий авторский уровень. Это предотвращает повреждение состояния и ошибочный пересчёт оставшихся ресурсов.

## Критерии приёмки

1. Визуальная доска остаётся 250×250.
2. Цветные блоки отчётливо крупнее прежних одиночных точек.
3. Один муравей переносит один крупный блок.
4. Счётчик показывает сотни блоков, а не десятки тысяч.
5. Сохраняются пять стартовых отсеков и резервная сетка 3×3.
6. Полный уровень имеет автоматизированную выигрышную последовательность.
7. Тесты и production build проходят; публичная main не меняется без отдельного подтверждения.
