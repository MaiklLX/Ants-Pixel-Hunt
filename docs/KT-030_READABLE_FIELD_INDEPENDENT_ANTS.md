# KT-030 — читаемое поле и независимые муравьи

## Цель
Снизить зрительную нагрузку на первом уровне и сделать работу колонии понятной с первого взгляда, особенно на небольших мобильных экранах.

## Изменения
- Сетка уровня уменьшена с 50×50 до 35×35 крупных блоков.
- Внутренний canvas увеличен до 350×350; геометрия лягушонка сохраняет исходные пропорции.
- Каждый занятый стартовый отсек обслуживается независимым муравьём и не ждёт окончания маршрута соседнего отсека.
- Целевой кубик исчезает с поля в момент захвата; на обратном пути муравей явно несёт кубик своего цвета.
- После каждого подбора доступность клеток пересчитывается, а ожидающие боксы получают возможность отправить муравья сразу после открытия подходящего блока.
- Анимации разных муравьёв и отправки опустевших боксов используют отдельные визуальные слои.

## Проверки
- [ ] npm test

- [ ] GitHub Actions: browser checks, Godot checks, Pages deploy.
- [ ] Ручная проверка на телефоне: читаемость рисунка, цвет бокса, параллельная работа 2–5 боксов, точка захвата и возврат кубика.

## Ограничения
Снижение сетки до 35×35 — баланс первого уровня, а не глобальное правило для всех будущих карт. Более сложные уровни могут использовать другой размер после мобильного тестирования.
