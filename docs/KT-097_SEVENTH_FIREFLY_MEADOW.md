# KT-097 — седьмая авторская полянка «Светлячок в сумерках»

**Дата:** 14 ноября 2026.  
**Статус:** код и регрессионный сценарий записаны в `main`; подтверждение полного CI и GitHub Pages для нового HEAD ещё ожидается.

## Цель

Расширить первую кампанию ещё одним самостоятельным пиксельным рисунком, не меняя правила головоломки, пять стартовых отсеков, лимиты боксов, последовательность конвейера или механику муравьёв.

## Новый уровень

- ID: `forest-07`.
- Номер: 7.
- Глава карты: «Светлячковая роща».
- Название: «Светлячок в сумерках».
- Силуэт состоит из двух крыльев, головы, грудного сегмента, вытянутого брюшка, светящейся нижней части, усиков и лапок.
- Размер поля остаётся 35×35; используются все пять существующих цветов.

Цветовые кольца строятся от воздуха, связанного с внешней границей, по четырёхсторонней дистанции: зелёный (первый наружный слой), голубой, сиреневый, жёлтый и красный (глубокая сердцевина). Это делает первый слой согласованным с реальным flood fill `getExposedPixels`, а не с диагональной близостью.

## Подтверждённая модельная проверка

В независимом V8 harness для того же силуэта и текущего алгоритма `buildIncoming` получено:

| Цвет | Блоков / муравьёв |
|---|---:|
| Зелёный | 105 |
| Голубой | 168 |
| Сиреневый | 134 |
| Жёлтый | 96 |
| Красный | 125 |
| **Всего** | **628** |

- Все 105 зелёных блоков доступны снаружи в начале; другие цвета в начальном открытом слое отсутствуют.
- Колода содержит 19 боксов; сумма лимитов каждого цвета точно равна числу блоков на поле.
- Все боксы укладываются в лимит `BOX_CAPACITY=60`.
- Сохранена связанная пара на позициях 12/13; запечатанный бокс остаётся на позиции 8.
- Поле очищается существующими `chooseTopColumn` и `resolveAll` по проверенной последовательности колонок (нумерация с нуля): `[1,2,0,0,1,0,2,2,2,0,2,2,2,1,1,0,0,0]`.

Эта последовательность добавлена как регрессионный тест, чтобы последующие изменения рисунка, очереди или правил не делали уровень нерешаемым незаметно.
