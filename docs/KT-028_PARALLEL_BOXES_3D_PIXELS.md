# KT-028 — параллельная подача и объёмные пиксели

## Изменения
- Можно выбирать следующий бокс, пока предыдущий едет по конвейеру.
- Каждый летящий бокс рисуется на отдельном прозрачном слое, поэтому анимации не стирают друг друга.
- Стартовые отсеки резервируются сразу при выборе; новые боксы занимают следующие свободные отсеки по порядку.
- Муравьи начинают работу только после завершения всех активных доставок.
- Перезапуск временно недоступен во время доставки, чтобы не оставить незавершённую анимацию.
- Каждый крупный пиксель получил светлую верхнюю/левую грань и затемнённую нижнюю/правую грань; тёмная грань теперь действительно отрисовывается по нижнему и правому краю каждого кубика.
- Физический порядок подачи на экране: лоток выбора → сортировочная лента → пять приёмных отсеков. Анимация движется по этому же маршруту.
- Сохранена компактная компоновка для мобильного экрана.

## Проверка
npm test и npm run build; затем визуальная проверка нескольких одновременных доставок на мобильном экране.
