# KT-033 — медленная извилистая колония

## Задача
Сделать наблюдение за работой колонии более спокойным и естественным: муравьи должны двигаться не строем по прямой, а по индивидуальным плавным тропам.

## Реализовано
- Увеличено количество контрольных точек на каждом маршруте.
- Для каждого муравья генерируется собственная комбинация изгибов и боковых отклонений.
- Выход группы растянут во времени: муравьи отправляются поочерёдно, но сохраняют количество, соответствующее доступным блокам их цвета.
- Поход к блоку и возвращение замедлены.
- Обратный маршрут отличается от пути к блоку.
- Подбор блока происходит в момент контакта, а не после завершения всей анимации.

## Ограничения
Маршруты пока строятся независимо друг от друга и не моделируют общие тропы колонии, столкновения или небольшие остановки-разведки. Это следующие возможные улучшения после проверки темпа на реальном устройстве.

## Проверка
Browser tests, production build и публикация Pages выполняются GitHub Actions. Субъективную плавность и нагрузку нужно дополнительно проверить на телефоне.
