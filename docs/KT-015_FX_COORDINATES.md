# KT-015 — устойчивые координаты анимации

## Что изменено

Ранее FX-слой вычислял локальные позиции через простое вычитание global_position. Такой расчёт корректен только при совпадающих масштабах и отсутствии дополнительных преобразований родителя.

Теперь все глобальные центры ячеек переводятся в локальную систему координат FX-слоя через обратную матрицу его global transform. Направление муравья также рассчитывается уже в локальной системе FX-слоя.

Это делает полёт, возвращение, передачу груза и импульс ячейки устойчивее при масштабировании и преобразованиях CanvasItem.

## Проверка

- [x] Заменено простое вычитание global_position на обратное преобразование global transform.
- [x] Направление полёта и возврата рассчитывается в координатах FX-слоя.
- [x] Проверено поиском по исходнику, что старых прямых смещений FX-слоя не осталось.
- [ ] Выполнить Godot 4.3 import и headless smoke test в CI.
- [ ] Проверить анимацию на реальных экранах Android, iOS и Web/PWA.

Изменение координат не считается подтверждённым на устройстве до визуального тестирования.
