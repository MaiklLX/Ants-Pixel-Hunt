# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Самостоятельная мобильная аркада-головоломка на Godot 4. Проект не связан с Game-ANTS.

## Концепция

Игрок выбирает группы муравьёв определённых цветов. Муравьи автоматически съедают пиксельные элементы соответствующего цвета на игровом поле. Задача — очистить поле, правильно выбирая группы и учитывая ограниченное количество мест для ожидания.

## Технологии

- Godot 4
- GDScript
- Целевые платформы: Android, iOS и Web/PWA
- Основной язык интерфейса: русский

## Запуск

1. Установите Godot 4.x.
2. Откройте в Godot файл `project.godot`.
3. Запустите главную сцену проекта.

## Статус

Ранняя разработка. Текущий этап — вертикальный прототип базового игрового цикла. Платформенные сборки и публикация ещё не заявлены как готовые.

## Принципы разработки

- Сохранять узнаваемый основной цикл цветовой пиксельной головоломки с автоматическим поеданием элементов.
- Создавать собственных персонажей, уровни, визуальный стиль, звук и метапрогрессию.
- Не копировать оригинальные материалы, уровни, интерфейс или аудио других игр.
- Проверять управление и читаемость отдельно на мобильных устройствах и в браузере.
- Фиксировать контрольные точки и проверять проект после каждого существенного этапа.
