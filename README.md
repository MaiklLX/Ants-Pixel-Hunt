# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Самостоятельная мобильная цветная пиксельная головоломка. Проект не связан с Game-ANTS.

## Текущий этап: KT-024 — крупные пиксельные блоки

Игровое поле визуально остаётся сеткой 250×250 квадратов, но рисунок формируется из крупных блоков 10×10. Один муравей переносит один такой блок целиком. В текущем портрете лягушонка 325 собираемых блоков вместо 62 500 отдельных клеток; партия использует 19 небольших боксов по 20 муравьёв максимум. Публичная `main` не изменяется — работа продолжается в черновой ветке PR #5.

## Игровой принцип

Игрок получает контейнеры с муравьями по одному и размещает их в пяти пусковых ячейках. У каждого контейнера свой цвет и ограниченное количество муравьёв. Муравьи уносят доступные крупные цветные блоки своего цвета, по одному блоку на каждого муравья. Удаление блока открывает соседние блоки.

Контейнер, которому пока нечего унести, ждёт в своей ячейке. Проигрыш наступает только когда все пять ячеек заняты, ни один контейнер не может сделать ход и на поле остались пиксели.

## Целевая архитектура

- HTML5 / CSS / JavaScript — браузерная игра.
- PWA — установка на главный экран iPhone и Android, автономный запуск.
- IndexedDB с fallback на localStorage — локальные сохранения без сервера.
- Capacitor 8 — Android-оболочка и сборка APK.
- Node.js — автоматические проверки игровых правил.

## Запуск разработки

Требуется Node.js 22+.

```bash
npm install
npm test
npm run build
npm run serve
```

Для Android после сборки web-клиента и установки Android Studio + Android SDK:

```bash
npx cap add android
npx cap sync android
npx cap open android
```
