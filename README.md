# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Уютная цветная головоломка о колонии муравьёв, которые постепенно собирают большой пиксельный рисунок.

## Играть

**Публичная браузерная версия:** https://maikllx.github.io/Ants-Pixel-Hunt/

Игра работает как мобильная веб-игра и PWA. Прогресс хранится локально на устройстве (IndexedDB с резервным сохранением в localStorage). Для автономного запуска после первой загрузки используется Service Worker.

## Текущая версия

**KT-034 — прогресс уровня и экран результата.**

- Поле 35×35 крупных цветных блоков; один муравей переносит один блок.
- Пять пусковых отсеков и последовательная сетка боксов 3×3.
- Боксы подаются через сортировочную ленту и работают независимо.
- Муравьи выходят постепенно, идут по индивидуальным плавным извилистым маршрутам и возвращаются с кубиком.
- Индикатор показывает количество оставшихся блоков и долю собранного портрета.
- Победа и поражение завершаются отдельным экраном с повтором уровня или возвратом в меню.

## Основные правила

1. Выбирай бокс только из верхнего ряда резервной сетки.
2. Бокс занимает первый свободный стартовый отсек и автоматически отправляет муравьёв на сбор блоков своего цвета.
3. Блок доступен, если хотя бы одна из четырёх сторон свободна или выходит к краю поля.
4. Каждый муравей переносит один блок. После его удаления могут открыться новые блоки.
5. Бокс, которому пока нечего собирать, остаётся ждать в своём отсеке.
6. Поражение наступает только когда все пять отсеков заняты, доступных ходов нет и на поле ещё остались блоки.

## Разработка и проверки

Требуется Node.js 22+.

```bash
npm install
npm test
npm run build
npm run serve
```

GitHub Actions автоматически запускает игровые тесты и production build, а затем публикует браузерную версию в GitHub Pages. Отдельный workflow проверяет сохранённый Godot-прототип.

## Архитектура и границы проекта

- Текущая публичная игра: HTML5 / CSS / JavaScript.
- PWA: локальное сохранение и автономная оболочка.
- Capacitor 8: подготовленная основа для Android-оболочки; готовность APK и публикация в магазинах отдельно не подтверждены.
- Исторический Godot-прототип сохранён в репозитории и не является текущей публичной браузерной версией.
- Проект самостоятельный и не связан с Game-ANTS.

## Что дальше

Приоритеты после KT-034: полноценный первый запуск с коротким интерактивным обучением, несколько авторских полянок и карта прогресса, пауза/настройки и звуковое оформление, затем расширенные тесты производительности на телефонах. Новые уровни должны иметь собственные рисунки и проверенный баланс цветовой очереди.
