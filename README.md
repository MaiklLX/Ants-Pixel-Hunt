# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Уютная цветная головоломка о колонии муравьёв, которые постепенно собирают большой пиксельный рисунок.

## Играть

**Публичная браузерная версия:** https://maikllx.github.io/Ants-Pixel-Hunt/

Игра работает как мобильная веб-игра и PWA. Открытые уровни кампании хранятся локально на устройстве. Незавершённая партия не сохраняется: возврат в главное меню или новый запуск игры сбрасывает текущий уровень. Для автономного запуска после первой загрузки используется Service Worker.

## Текущая версия

- Главное меню, карта приключений и муравейник оформлены как единый лесной мир: пунктирные тропы, глубокие земляные слои, каменные поверхности и мягкий свет колонии. Главное меню сохраняет передний план диорамы, движение листвы и независимые ритмы светлячков. Игровые анимации муравьёв и боксов замораживаются при уходе страницы в фон и продолжаются с той же фазы после возвращения.

**KT-079 — более дешёвое вычисление позы муравья; KT-078 — карта лесных троп и архитектура муравейника.**

- Шесть полянок с уникальными пиксельными рисунками: лягушонок, бабочка, цветок, гриб, жёлудь и улитка.
- Победа открывает следующую полянку; открытые уровни сохраняются между запусками.
- Текущее состояние поля, боксов и муравьёв не сохраняется: выход в меню и закрытие игры начинают уровень заново.
- Поле 35×35 крупных цветных блоков; один муравей переносит один блок.
- Пять пусковых отсеков и последовательная сетка боксов 3×3.
- Боксы подаются через объёмный анимированный конвейер и работают независимо.
- Размеры боксов различаются; общий запас муравьёв каждого цвета точно равен числу блоков этого цвета. Крупный бокс может надолго занять отсек, поэтому выбор имеет значение.
- Одновременно анимируется ограниченное число муравьёв, а поле перерисовывает только изменившиеся блоки для более плавной работы на телефонах.
- Колония рисуется на общем canvas/RAF: одна выборка Catmull–Rom вычисляет позицию и направление каждого муравья, не меняя его индивидуальную траекторию.
- Муравьи выходят постепенно, идут по индивидуальным плавным извилистым маршрутам и возвращаются с кубиком.
- Индикатор показывает количество оставшихся блоков и долю собранного портрета.
- Победа и поражение завершаются отдельным экраном с повтором уровня, переходом к следующему или возвратом в меню.

## Основные правила

1. Выбирай бокс только из верхнего ряда резервной сетки.
2. Бокс занимает первый свободный стартовый отсек и автоматически отправляет муравьёв на сбор блоков своего цвета.
3. Доступен только внешний слой: пустая область должна иметь непрерывный путь к внешнему краю рисунка. Закрытые внутренние пустоты не открывают блоки.
4. После снятия внешнего слоя открывается следующий; планируй цветовые боксы и пять отсеков заранее.
5. Каждый муравей переносит один блок. После удаления внешних блоков постепенно открывается следующий слой.
6. Бокс, которому пока нечего собирать, остаётся ждать в своём отсеке.
7. Поражение наступает только когда все пять отсеков заняты, доступных ходов нет и на поле ещё остались блоки.
8. У каждого бокса свой лимит муравьёв. Следи за числом на коробке: лишнего запаса нет.

## Разработка и проверки

Требуется Node.js 22+.

```bash
npm install
npm test
npm run build
npm run serve
```

GitHub Actions автоматически запускает игровые тесты и production build, а затем публикует браузерную версию в GitHub Pages. Отдельный workflow проверяет сохранённый Godot-прототип.

## Архитектура и границы проекта

- Текущая публичная игра: HTML5 / CSS / JavaScript.
- PWA: локальное сохранение и автономная оболочка.
- Capacitor 8: подготовленная основа для Android-оболочки; готовность APK и публикация в магазинах отдельно не подтверждены.
- Исторический Godot-прототип сохранён в репозитории и не является текущей публичной браузерной версией.
- Проект самостоятельный и не связан с Game-ANTS.

## Что дальше

Следующий этап: довести кампанию до 20 уровней первой главы, затем добавить новые механики (веточки-преграды, цветочные бонусы, хрупкие блоки) только после отдельного тестирования баланса. После этого — релакс и бесконечный режимы.
