# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Самостоятельная мобильная цветная пиксельная головоломка на Godot 4. Проект не связан с Game-ANTS.

## Игровой принцип

Игрок получает контейнеры с муравьями по одному и размещает их в пяти пусковых ячейках. У каждого контейнера свой цвет и ограниченное количество муравьёв. Муравьи уносят все доступные пиксели своего цвета, по одному на каждого муравья. Удаление пикселей открывает соседние.

Контейнер, которому пока нечего унести, ждёт в своей ячейке. Проигрыш наступает не за неправильный выбор цвета, а только когда все пять ячеек заняты, ни один контейнер не может сделать ход и на поле остались пиксели.

3. Запустите главную сцену.

## Статус

Прототип KT-011. Реализованы цветное поле с доступностью по четырём сторонам, пять пусковых ячеек, последовательная очередь контейнеров, автоматическая обработка слева направо, авторский векторный муравей и цикл сбора с возвращением груза. Runtime-проверка Godot 4.3 и тестирование на реальных устройствах ещё не подтверждены.

GitHub Actions выполняет импорт проекта и короткий smoke test на Godot 4.3 при каждом push в `main` и при pull request.
