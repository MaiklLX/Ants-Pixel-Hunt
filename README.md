# Муравьишки: Пиксельная охота

**Маленькие герои. Большая охота!**

Самостоятельная мобильная цветная пиксельная головоломка. Проект не связан с Game-ANTS.

## Игровой принцип

Игрок получает контейнеры с муравьями по одному и размещает их в пяти пусковых ячейках. У каждого контейнера свой цвет и ограниченное количество муравьёв. Муравьи уносят все доступные пиксели своего цвета, по одному на каждого муравья. Удаление пикселей открывает соседние.

Контейнер, которому пока нечего унести, ждёт в своей ячейке. Проигрыш наступает не за неправильный выбор цвета, а только когда все пять ячеек заняты, ни один контейнер не может сделать ход и на поле остались пиксели.

## Целевая архитектура

- HTML5 / CSS / JavaScript — браузерная игра.
- PWA — установка на главный экран iPhone и Android, автономный запуск.
- IndexedDB с fallback на localStorage — сохранения на устройстве без сервера.
- Capacitor 8 — Android-оболочка и сборка APK.
- Node.js — автоматические проверки игровых правил.

## Запуск разработки

Требуется Node.js 22+.

```bash
npm install
npm test
npm run build
npm run serve
```

Для Android после сборки web-клиента и установки Android Studio + Android SDK:

```bash
npx cap add android
npx cap sync android
npx cap open android
```
