# Каталог спрайтов и мастерская импорта

Основная библиотека: [Tiddybub/2d-assets](https://github.com/Tiddybub/2d-assets).

Каталог в `catalog.json` содержит тематическую выборку из 13 проверенных по индексу upstream-паков, пригодных для будущих полянок. Список намеренно не копирует все 1101 набора: в первую очередь отобраны животные/персонажи, растения, еда, предметы, транспорт и фантастические объекты.

## Как использовать

1. Откройте папку нужного набора по ссылке из `catalog.json`.
2. Скачайте исходный спрайт/лист и при необходимости обрежьте один объект.
3. Откройте `sprite-lab.html` в браузере (в опубликованной игре: `/tools/sprite-lab.html`).
4. Загрузите PNG/WebP/JPG, подберите количество цветов и экспортируйте JSON.
5. Проверьте силуэт и распределение цветов. Не добавляйте автоматически: рисунок должен быть узнаваемым и давать интересный игровой слой.
6. При включении в кампанию сохраните ссылку на исходный пак и файл `SOURCE.md`.

## Формат экспорта

- Сетка 45×45; одна ячейка — один собираемый блок.
- `palette` — компактная палитра RGB→HEX.
- `data` — 45 строк через `/`, индексы палитры в base36, `.` — прозрачная ячейка.
- `source` — происхождение изображения и лицензия.

Мастерская работает локально в браузере и не загружает изображения на сервер. Она не меняет `src/game.js`, генератор очереди, правила пяти отсеков или текущие уровни. Экспорт — подготовленный материал, а не автоматическая публикация уровня.

## Лицензии

README библиотеки Tiddybub/2d-assets указывает CC0 для всех включённых паков и наличие `SOURCE.md` в каждом паке. Сохраняйте исходные сведения при переносе файлов; если условия конкретного набора изменятся, обновите запись до использования.
